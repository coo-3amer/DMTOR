# MZ-DManager Lite (Windows 7 edition)

A small, separate download manager for Windows 7 SP1 and newer: files only (no videos, no torrents).
Its own name, install folder, settings (`%APPDATA%\MZ-DManager Lite`), browser extension and port (9615),
so it never touches MZ-DManager.

Built by `.github/workflows/build-lite.yml` on the `win7` branch. Installer: branch `download-win7`.
